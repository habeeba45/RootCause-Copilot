# RootCause Copilot: technical audit (2026-11-19)

Scope: the whole application, checked end to end. That covers the LLM integration, dynamic tool selection, evidence correlation,
file validation, persistence, investigation history and report downloads. Method: code review, the automated suite
(`backend/tests`, 26 tests), live HTTP calls, and browser runs (Playwright) against the real backend and frontend.

## Issues found and fixed in this audit

1. **SQLite persistence did not exist.** Incidents were JSON files and events were written only at the end of a run, so a crash lost the whole log. Now SQLite holds incidents, input files (BLOB), runs and events, and each event is written as it happens. Legacy data is migrated.
2. **No investigation history.** Re-run replaced the previous result. Every run is now kept, viewable and downloadable.
3. **Misleading "time to RCA".** The reported duration included the deliberate display pause between agent steps (about 0.45 s × ~40 steps). `duration_s` is now real compute time; `wall_clock_s` and `display_pacing_s` are reported separately. The default pause was lowered to 0.3 s and can be set to 0 with `AGENT_STEP_DELAY`.
4. **Rejected LLM tool calls were not flagged as errors** to Anthropic. `is_error: true` is now set on those tool results.

## Simulated or limited parts (by design, stated honestly)

- **Sample incidents are synthetic** (generated by `scripts/generate_samples.py`) and labelled as samples. Uploaded data is processed exactly the same way.
- **Display pacing**: the agent pauses briefly between steps so people can watch the live log. It is cosmetic and excluded from metrics.
- **Detection is heuristic, not a trained model**: robust z-scores (median/MAD), keyword-based log classification and weighted evidence checks. The weights are hand-set.
- **Confidence is relative, not a calibrated probability.** It is a softmax over evidence scores among the tested hypotheses plus an "unexplained" alternative, and the UI says so.
- **Recommendations come from a playbook** (templated per failure type). LLM-suggested actions are added only when they cite evidence.
- **Single-user, local tool**: no authentication; CORS is open for local development; files are capped at 50 MB and processed in memory.
- **PDF**: use the browser's "Print to PDF" on the HTML report; there is no built-in PDF generator.
- **Live LLM success** must be confirmed by the owner with a real key: use **Test connection** in the sidebar, then run a sample.
